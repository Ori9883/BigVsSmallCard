# BigVsSmall 道具系统设计草案

## 1. 设计目标

当前游戏的核心乐趣来自 **颜色公开、数字隐藏、先后手交替、每轮分值不同** 所形成的信息博弈。道具系统的目标不是简单强化玩家，而是让每一轮出牌前后出现更多类似《恶魔轮盘》的判断：

- 是否值得为了当前轮暴露或消耗资源。
- 是否相信自己获得的情报。
- 是否在高分轮加码或止损。
- 是否用道具逼迫对方进入不舒服的出牌区间。
- 是否保留关键道具等待 30 分轮或残局。

道具应尽量服务以下几类体验：

1. **信息差**：查看、隐藏、伪装、误导。
2. **风险下注**：提高收益，同时承担更大失败代价。
3. **规则扰动**：临时改变某一轮的胜负判定。
4. **节奏控制**：限制颜色、限制道具、改变下一轮压力。
5. **心理博弈**：玩家和敌人都需要判断对方是否有反制或陷阱。

## 2. 道具定义框架

每个道具统一按以下字段定义，便于后续转化为配置表、`ScriptableObject` 或代码枚举。

```text
道具名：
使用时机：先手前 / 后手响应 / 揭示前 / 任意
目标：自己 / 对方 / 本轮 / 下一轮 / 手牌 / 弃牌堆
信息强度：无 / 模糊 / 精确 / 错误信息
风险：无 / 失败空放 / 反噬 / 对方也受益
是否可被反制：是 / 否
AI 使用难度：低 / 中 / 高
具体规则：
设计意图：
平衡限制：
```

### 2.1 使用时机定义

道具使用时机只保留与玩家决策强相关、且不会破坏结算体验的阶段。

| 使用时机 | 说明 |
| --- | --- |
| 先手前 | 本轮先手方出牌前。包括上一轮结算结束后到本轮先手方确认出牌前的准备阶段。 |
| 后手响应 | 先手方已经出牌，后手方尚未出牌。 |
| 揭示前 | 双方均已经出牌，但是牌还没揭开。 |
| 任意 | 在以上所有时机都能使用。 |

### 2.2 信息强度定义

| 信息强度 | 说明 |
| --- | --- |
| 无 | 不提供任何牌面信息。 |
| 模糊 | 提供部分信息，例如颜色、数字、范围、是否存在。 |
| 精确 | 直接看到某张牌的完整数字或颜色加数字。 |
| 错误信息 | 主动制造假信息或伪装信息。 |

### 2.3 风险定义

| 风险 | 说明 |
| --- | --- |
| 无 | 使用后稳定生效，无直接反噬。 |
| 失败空放 | 条件不满足时道具被消耗但没有收益。 |
| 反噬 | 使用失败或判定不利时，使用者受到惩罚。 |
| 对方也受益 | 道具改变公共规则，可能让对方也获得收益。 |

## 3. 道具规则列表

## 3.1 随机线索

```text
道具名：随机线索
使用时机：先手前
目标：对方手牌
信息强度：模糊
风险：无
是否可被反制：是
AI 使用难度：低
```

### 具体规则

使用后，随机从对方当前未出的手牌中抽取一张，并给出一条不完整信息。

信息可以从以下类型中随机选择：

1. 颜色加数字信息：例如“对方绿色牌中有一张 4”。
2. 仅数字信息：例如“对方手牌中存在一张 5”。
3. 仅颜色数量信息：例如“对方还剩 2 张蓝色牌”。

第一版建议只使用第 1 种：**颜色加数字信息**。它最直观，也和当前“颜色公开、数字隐藏”的核心规则结合最紧密。

### 设计意图

补偿先手的信息劣势，让先手不只是盲打。该道具不直接决定胜负，而是帮助玩家判断本轮是否值得打高牌、是否应该保留 1 或 5。

### 平衡限制

- 每次只提供一条信息。
- 不允许指定颜色或数字。
- 如果对方手牌数量过少，该道具价值会变高，需要控制出现频率。
- 可以被“道具封锁”或“手铐”限制。

## 3.2 盖牌烟雾

```text
道具名：盖牌烟雾
使用时机：先手前
目标：自己本轮出牌
信息强度：错误信息 / 信息隐藏
风险：无
是否可被反制：是
AI 使用难度：中
```

### 具体规则

使用后，自己本轮作为先手打出的牌不会向后手展示真实颜色。

表现上可以有两种方案：

1. **完全隐藏颜色**：牌背显示为烟雾或黑色通用牌背。
2. **伪装颜色**：牌背随机显示为另一个颜色。

第一版推荐使用 **完全隐藏颜色**，规则更清晰，避免玩家误以为颜色真的被改变。

### 设计意图

削弱后手优势，让后手无法根据颜色推断数字分布或剩余牌结构。适合在高分轮、关键牌或诱导局中使用。

### 平衡限制

- 只影响本轮先手出的这一张牌。
- 不改变真实颜色和数字。
- 揭示时必须显示真实牌面。
- 可以被“放大镜”查看数字，但“放大镜”是否同时看到颜色需要单独配置。第一版建议放大镜只看数字，不破解颜色隐藏。

## 3.3 下注加码

```text
道具名：下注加码
使用时机：先手前
目标：本轮分值
信息强度：无
风险：对方也受益
是否可被反制：是
AI 使用难度：中
```

### 具体规则

使用后，本轮基础分值翻倍。双方按翻倍后的分值结算。

例如：

- 当前轮基础分为 10，使用后胜者获得 20。
- 当前轮基础分为 30，使用后胜者获得 60。

### 设计意图

制造类似赌博加注的压力。因为先手在不知道对方将出什么牌的情况下加码，所以该道具天然有风险。

### 平衡限制

- 只能在自己先手前使用。
- 每轮最多只能有一次加码效果。
- 不建议允许和其他分值翻倍类效果叠乘。
- 可以被“道具封锁”或“手铐”提前限制，但一旦加码成功，本轮分值不再被取消。

## 3.4 锁色

```text
道具名：锁色
使用时机：先手前
目标：双方下一次出牌选择
信息强度：无
风险：对方也受益
是否可被反制：是
AI 使用难度：中
```

### 具体规则

使用者选择一种颜色。下一轮双方都不能主动打出该颜色的手牌。

如果某一方手里只剩被锁定颜色的牌，则该方可以无视锁色效果，正常出牌。

### 设计意图

把颜色从“信息载体”进一步变成“可操作资源”。玩家可以根据已知弃牌、手牌颜色和推理结果，限制对方可能的强牌。

### 平衡限制

- 锁色只持续一轮。
- 不允许连续两轮锁同一种颜色。
- 当锁色导致玩家无合法出牌时，必须自动解除对该玩家的限制，避免死局。
- UI 必须明确显示当前被锁颜色。

## 3.5 道具封锁

```text
道具名：道具封锁
使用时机：先手前
目标：双方道具使用权限
信息强度：无
风险：对方也受益
是否可被反制：否
AI 使用难度：低
```

### 具体规则

使用后，下一轮双方都不能使用任何道具。

如果某个道具已经在上一轮结算后生效，并影响下一轮，则该持续效果仍然保留；“道具封锁”只禁止下一轮中新的主动使用。

### 设计意图

提供一个“回归纯牌局”的控制手段。领先方可以用它保护优势，落后方也可以用它阻止对手在高分轮继续扩大优势。

### 平衡限制

- 只持续一轮。
- 不可被反制，否则规则会变得过于套娃。
- 不应过多出现，否则会削弱道具系统存在感。

## 3.6 王牌化

```text
道具名：王牌化
使用时机：揭示前
目标：自己本轮出牌
信息强度：无
风险：反噬
是否可被反制：是
AI 使用难度：中
```

### 具体规则

使用后，自己本轮打出的牌在比大小时视为数字 5。

但该牌仍然遵守特殊规则：**数字 1 可以击败数字 5**。

因此，如果对方实际或视为数字 1，则对方获胜。

### 设计意图

提供强力翻盘手段，但保留明确弱点。它不是无脑胜利，而是会被 1 克制，能制造“我赌你没有 1”的紧张感。

### 平衡限制

- 不改变牌的真实数字，只改变本轮判定数字。
- 不能和“最小即最大”同时作用于同一张牌。
- 如果双方都使用改变判定数字的道具，按道具使用顺序或优先级结算。第一版建议禁止同轮重复改写同一方点数。

## 3.7 最小即最大

```text
道具名：最小即最大
使用时机：揭示前
目标：自己本轮出牌
信息强度：无
风险：失败空放
是否可被反制：是
AI 使用难度：中
```

### 具体规则

使用后，如果自己本轮打出的牌真实数字为 1，则该牌本轮视为最大牌，并可以击败所有数字，包括 5。

如果自己本轮打出的牌不是 1，则道具消耗但无效果。

### 设计意图

强化小牌价值，让 1 不只是针对 5 的特殊解，而是可以成为高风险爆发点。该道具适合配合信息道具或后手判断使用。

### 平衡限制

- 只对真实数字为 1 的牌生效。
- 不建议让它作用于被“王牌化”变成 5 的牌。
- 可以被“放大镜”提前识破风险，但不能直接阻止。

## 3.8 平局获胜

```text
道具名：平局获胜
使用时机：揭示前
目标：本轮胜负判定
信息强度：无
风险：失败空放
是否可被反制：是
AI 使用难度：低
```

### 具体规则

使用后，如果本轮原本会结算为平局，则改为使用者获胜，并获得本轮分值。

如果本轮不是平局，则道具消耗但无效果。

### 设计意图

让玩家在已知或猜测对方数字时，可以主动追求同点牌。它适合和“放大镜”“随机线索”等信息类道具形成组合。

### 平衡限制

- 只改变平局，不改变胜负已分的结果。
- 如果双方都使用“平局获胜”，则平局仍为平局，或按先使用者生效。第一版推荐：双方都使用时相互抵消。

## 3.9 赢家诅咒

```text
道具名：赢家诅咒
使用时机：揭示前
目标：本轮赢家与下一轮先后手
信息强度：无
风险：对方也受益
是否可被反制：是
AI 使用难度：中
```

### 具体规则

使用后，本轮正常结算分数，但本轮赢家在下一轮必须成为先手。

如果本轮平局，则该道具不改变下一轮先后手。

### 设计意图

把“赢当前轮”和“下一轮信息劣势”绑定起来。玩家可以在预计自己要输时使用，让对方虽然拿分，但下一轮被迫先手。

### 平衡限制

- 只影响下一轮。
- 如果下一轮已经被其他效果强制指定先后手，需要定义优先级。第一版建议：后生效的先后手改变覆盖先生效的改变。
- 最后一轮使用无意义，应禁止或提示不可用。

## 3.10 手铐

```text
道具名：手铐
使用时机：先手前
目标：对方道具使用权限
信息强度：无
风险：无
是否可被反制：是
AI 使用难度：低
```

### 具体规则

使用后，对方下一轮不能主动使用道具。自己仍然可以使用道具。

如果对方已有持续中的道具效果，该效果不被移除；手铐只限制下一轮新的主动使用。

### 设计意图

这是“道具封锁”的单体强力版本，适合在高分轮前压制对方反制能力，也能制造《恶魔轮盘》式的节奏控制感。

### 平衡限制

- 只持续一轮。
- 可以被特定免疫类效果反制；如果第一版没有免疫道具，则只允许被“道具封锁”这种全局规则覆盖。
- 出现频率应低于普通信息道具。

## 3.11 放大镜

```text
道具名：放大镜
使用时机：后手响应 / 揭示前
目标：对方本轮已出牌
信息强度：精确
风险：无
是否可被反制：是
AI 使用难度：低
```

### 具体规则

当对方已经出牌后，使用者可以查看对方本轮已出牌的真实数字。

第一版建议只查看数字，不查看或破解颜色隐藏状态。

例如：

- 对方先手打出一张背面为蓝色的牌。
- 玩家使用放大镜，得知该牌数字为 4。
- 玩家仍需自行选择出牌应对。

### 设计意图

这是最基础、最直观的信息道具。它能显著提升后手决策质量，但不直接改变胜负，因此适合作为系统教学道具。

### 平衡限制

- 只查看当前已出的那张牌。
- 不查看对方手牌。
- 不改变牌面、不改变分数。
- 可被“道具封锁”或“手铐”限制。

## 3.12 啤酒

```text
道具名：啤酒
使用时机：先手前
目标：对方手牌
信息强度：模糊 / 精确
风险：无
是否可被反制：是
AI 使用难度：中
```

### 具体规则

借鉴《恶魔轮盘》中“排出当前弹药”的感觉，但当前游戏是固定 7 轮手牌结构，不建议真的让对方弃牌，否则会破坏回合数量。

第一版规则建议为：

使用后，随机选择对方一张未出的手牌，将其 **公开信息** 给双方，然后该牌仍保留在对方手牌中。

公开信息可以有两个强度版本：

1. **温和版**：只公开颜色和数字，但不移除该牌。
2. **强力版**：公开颜色和数字，并且该牌下一轮不能被打出。

第一版推荐使用 **温和版**。

### 设计意图

啤酒负责制造“把暗牌从黑箱里晃出来”的感觉。它不直接让对方损失手牌，但会破坏对方隐藏信息，改变后续推理局势。

### 平衡限制

- 不应真的弃掉手牌，避免破坏 7 轮结构。
- 如果对方只剩 1 张手牌，使用价值极高，需要允许但控制出现频率。
- 公开的信息双方都能看到，因此有“对方也受益”的潜在效果：对方知道你已经知道这张牌。

## 4. 第一版推荐落地顺序

为了降低实现复杂度，建议按以下顺序落地：

1. **放大镜**：最简单的信息类道具，可验证道具使用时机和 UI 流程。
2. **随机线索**：验证手牌信息抽样和提示文本。
3. **下注加码**：验证分值修改与结算系统。
4. **锁色**：验证出牌合法性过滤。
5. **手铐**：验证单方道具禁用。
6. **道具封锁**：验证全局道具禁用。
7. **王牌化**：验证本轮临时点数改写。
8. **最小即最大**：验证条件型点数改写。
9. **平局获胜**：验证结算结果改写。
10. **赢家诅咒**：验证下一轮先后手改写。
11. **盖牌烟雾**：验证牌背表现和信息隐藏。
12. **啤酒**：验证公开手牌信息和长期信息状态。

## 5. 后续待讨论问题

1. 道具是双方每局随机获得，还是每轮刷新商店 / 抽取？
2. 玩家和敌人是否使用同一套道具池？
3. 每名角色同时最多持有几个道具？
4. 道具是否有稀有度，例如普通、稀有、危险？
5. 高分轮前是否应提高控制类道具的出现概率？
6. 敌人 AI 是否需要理解道具组合，还是第一版只做简单规则触发？
7. 道具信息是否要完整公开给玩家，还是敌人持有道具保持隐藏？
